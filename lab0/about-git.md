1. Чем ветка отличается от копии папки с проектом?
С помощью веток можно делать какие-то изменения в проекте, которые хранятся в своем контейнере. В любой момент можно вернуться к основной версии проекта, либо перейти в другую в ветку.
2. Что произойдёт с историей, если удалить папку проекта, но сохранить `.git`?
Вся история коммитов, веток и настройки репозитория сохранится. Для восстановления нужно ввести git restore.
3. Зачем нужен Pull Request, если можно коммитить сразу в `main`?
1) Пул реквест можно удобно откатить; 2) Предотвращение мерж конфликт; 3) Проведение код ревью; 4) Обсуждение пул реквеста на самой странице пул реквеста
